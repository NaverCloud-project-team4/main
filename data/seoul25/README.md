# 서울 25개 구 데이터 (kauroong)

| 파일 | 내용 |
|---|---|
| `04_zones_seoul25.sql` | 서울 25개 구 경계(Polygon)와 대표점. 번호 1~25는 행정구역 코드순이다 |
| `forecast_spots.csv` | 예측 지점 25곳(구마다 1곳). 좌표, 구 판정 결과, 경계까지 거리, 좌표 출처 |
| `05b_forecast_spots_seed.sql` | 예측 지점 25곳 INSERT 문 |
| `preview.html` | 구 경계와 지점을 한 지도에서 확인하는 미리보기(브라우저로 열기) |

## 좌표 규칙

- 좌표는 WGS84 경도·위도이고, WKT는 `POINT(경도 위도)` 순서다.
- 예상 절정일은 산림청 '2026년 한반도 단풍절정 예측지도'(2026-09-22 발표)의 수종별 값이다. 은행나무류 10/30, 단풍나무류 10/31이며, 서울 개별 지점의 산림청 예측일은 확인하지 못했다.

## 출처

- 구 경계: 통계청 SGIS 행정동 경계(공공누리 제1유형)를 가공한 파생물이며 CC BY 4.0이다. `04_zones_seoul25.sql` 맨 위의 출처 문구는 지우지 않는다.
- 지점 좌표는 대부분 Google Places에서 확인했다(`forecast_spots.csv`의 좌표 출처 열 참고).
- 이 SQL 파일은 우리가 만든 BIGINT 기반 로컬 스키마용이다. 저장소의 문자열 ID 스키마에는 마이그레이션으로 옮겨 쓴다(`docs/kauroong-confirmed-spec.pdf` 6, 7절).
